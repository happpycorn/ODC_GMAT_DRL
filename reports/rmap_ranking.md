# 規則敏感度地圖 rmap_ranking

- 基底 `ranking_like`：單發 追250/躲250、燃料 追3000/躲3000、窗口 300 s、半徑 5 km、T_max 4 週期、先手 pursuer、1 發/回合、continuous、J2
- 每格 n = 24 局（同一批幾何；各格 n 見細節表）
- 配對：rr = rollout 追 vs rollout 躲；strong = 強化版追 vs rollout 躲；escape = rollout 追 vs 逃逸躲；lambert = Lambert 追 vs rollout 躲（對照：Lambert 追者不會「判斷全輸就不追」）
- 格內：追者勝率 [95% Wilson 區間]。「vs 基底」= 跟基底格同一局逐局配對：+只有本格抓到 / −只有基底抓到，p = 雙尾精確符號檢定；**粗體** = p < 0.05（幾十個檢定裡約 5% 會是偽陽性，單一個 p≈0.03 要保守看）
